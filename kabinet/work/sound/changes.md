# Пакет 21 · Звук — что сделано

Копия: `work/sound/kabinet.html`. База: `base/kabinet_hd_5.html`. Патч: `work/sound/sound.patch`.

## 0. Аудит: что было до пакета

В базе уже было **два звуковых слоя**. Счёт «2 упоминания AudioContext» их не отражает: оба слоя используют один `AU.ctx`.

1. **`AU`** («Кабинет 3», блок «ЗВУК» в интерфейсе ПК). Чиптюн на `square`/`sawtooth`: 15 имён `AU.sfx(n)` (`sel ok up down vote end page pen stamp heart news lock paw coin big`) и прямые `AU.tone()/AU.noise()`. В коде около 140 вызовов. По умолчанию звук **выключен** (`PREF.sound=false`).
2. **«Озвучка 2.0»** (`window.AU2`, перед пакетом 17). Шины, ревербератор, библиотека FX (выстрелы, танки, монеты, предметы магазина), формантное «мяу» для реплик (`say`/`blip`, слова звучат «пачкой», без ритма текста), чиптюн-темы по срокам (glock + pizz + марш), фон по семействам сцен, баннер «Со звуком?».

**Проблемы, которые нашёл:**
- если звук был включён, AudioContext создавался **до жеста**: `tick` «Озвучки 2.0» через 50 мс после загрузки вызывал `AU.init()`;
- звучание 8-битное: квадратные волны в базовых эффектах и темах;
- «мяу» не в ритме текста, у разных котов почти одинаковые голоса, интонация не меняется;
- музыка не реагирует на напряжение, у ключевых сцен нет своих тем;
- кнопка «упирается» звучит тем же квадратным `lock`;
- у трёх слоёв свои громкости, а mute и ползунки разнесены.

## 1. Архитектура

- Новый блок **`<script id="p21-sound">`** в конце `body` (стр. 18302). В нём весь движок, `window.SFX`, панель настроек и CSS (`#p21-sound-css`).
- Граф: источники → шины `music / sfx / voice / amb` (у music и amb есть узел ducking) → `master` → лёгкий highshelf −3 дБ → лимитер → выход. Один ревербератор: сгенерированная импульсная характеристика «деревянного кабинета» 2,4 с с ранними отражениями. Посылы на него идут через шины, поэтому громкость шины гасит и её реверберацию.
- «Озвучка 2.0» оставлена ради библиотеки FX (покупки, события из текста карточки, звонок, перо на `.sigpad`). Её выход перенаправлен в движок (`P.legacy`). Свои голоса, музыку, базовые эффекты и фон кабинета она отдаёт движку через хуки `SFX.owns()`.
- **AudioContext** создаётся только в `ensure()`: после первого жеста (`pointerdown / keydown / touchend` или `navigator.userActivation.hasBeenActive`) и только если звук не выключен. `AU.init` перехвачен, `AU.ctx` — тот же контекст.
- **Без щелчков:** у каждого звука огибающая (атака ≥ 3 мс, экспоненциальное или линейное затухание до −80 дБ), шумовые петли бесшовные, смены тем и фона идут через `cancelAndHoldAtTime` и рампы.
- **Лимит голосов:** до 22 одновременных событий. Сверх лимита первыми отбрасываются `ui.*`, при +8 — любые. У каждого звука есть минимальный интервал повтора. Слоги речи планируются порциями по 120 мс вперёд, а не все сразу.
- **Настройки** хранятся в `localStorage['kab-p21-sound']`: `{muted, master, music, sfx, voice, amb, meow, tts}` и зеркалятся в `PREF.sound` и `PREF.vol`. Поэтому старые переключатели (кнопка «Звук», клавиша S, меню Депутата) и «Озвучка 2.0» работают согласованно. Новый игрок по умолчанию получает звук включённым, а кто раньше отказался (`PREF.sndAsked && !PREF.sound`), получает его выключенным. Старый баннер «Со звуком?» скрыт.

## 4. Кошачьи голоса

Синтез: глоттальный источник (волна 1/k^1.15) и шум дыхания → три формантных полосовых фильтра (F1–F3) и тёплый «корпус» → огибающая. **Каждая гласная текста становится «мя»-слогом**, гласная задаёт форманты (а/о/у/э/и/ы). Согласная перед гласной задаёт начало слога: `м` — носовое, `р` — раскатистое «мрр», `п/т/к/б/д/г` — короткое, `ш/с/х…` — с придыханием. Конец слова и фразы скользит в «‑у» (получается «мяу»). Темп привязан к набору текста: 34 зн/с в карточках (под паузу `700 + 28·len` мс), 45 зн/с у Депутата. Длинная реплика обрывается через 2,4 с (у Депутата через 4 с).

**Интонация по эмоции.** В данных игры эмоций нет, поэтому они выводятся из текста. Явно эмоцию можно передать так: `SFX.say(who, text, {emo:'angry'})`.
- `!` в конце — выше, громче, быстрее, ударный последний слог;
- `?` — подъём на последнем слоге (+4,5 полутона);
- `…` — тише, медленнее, падение;
- КАПС — крик с хрипотцой;
- словари: радость (`ура, спасибо, отлично`), гнев (`предатель, немедленно, арест`), страх (`помогите, боюсь`), печаль (`погиб, жаль, увы`);
- тяжёлая сцена (`SC.sev ≥ 3`) — чуть быстрее и выше;
- запятая — слог без падения, вопрос внутри фразы — подъём.

**Архетипы:** `man, tom` (крупный кот), `boss` (дон), `gruff` (военный), `woman, lady, girl, old_m, old_f, sly, whisper, posh, nerd, young, kitten, radio`.

## 5. Музыка и эмбиент

Генеративный планировщик с упреждением 0,3 с. Инструменты: войлочное пиано, тёплый пэд (детюн ±6 центов, плавающий фильтр), виолончель с отложенным вибрато, пиццикато, челеста, музыкальная шкатулка, латунь с «открытием» фильтра, литавры, кларнет, тремоло струнных. Темы сменяются **кроссфейдом 2,6–2,8 с**. Во время речи музыка приглушается до 60 %, во время крупных стингеров — до 45 %.

| Состояние | Когда | Характер |
|---|---|---|
| `menu` | стартовый экран, бюллетень | Главная тема «Кабинет» (ре минор, пиано). Каждые 8 тактов меняется подача: пиано → +виолончель → +шкатулка → свободная импровизация |
| `calm` | в игре, напряжение < 0,45 | Фа мажор, Fmaj7–Dm9–B♭maj7–Csus: редкое пиано по пентатонике, пэд, виолончель, иногда челеста |
| `tense` | 0,45–0,72 | Ре минор, остинато баса восьмыми, тёмный пэд, тиканье в музыке, литавра на такт |
| `crisis` | > 0,72, «Последняя ночь» | До минор на педали: удары сердца, тремоло струнных, латунные нарастания, диссонансы челесты |
| `vote` | голосование | Пиццикато «счёт», литавры; фильтр пэда и виолончель раскрываются по мере подсчёта |

**Напряжение (0–1)** складывается из нескольких слагаемых:
- неделя срока — 0,14;
- угроза `S.thr` — 0,28;
- худшая шкала — 0,2 (взвешена слабо, чтобы музыка не выдавала скрытые цифры);
- «Последняя ночь» — +0,5, предупреждение — +0,14, «под давлением» — +0,1, теневая карта — +0,06;
- тяжесть сцены (`SC.sev`) — до +0,12;
- III срок и бункер — по +0,06;
- наезд камеры раздумья — +0,12.

Переходы между состояниями с гистерезисом: вверх через 1,5 с, вниз через 7 с. Внутри состояния плавная «интенсивность» добавляет слои.

**Эмбиент кабинета** (семейство сцен `room`):
- тишина комнаты (бурый шум ниже 180 Гц);
- **часы «тик-так»**, громче при напряжении;
- **дождь за окном**: погода случайная на каждый срок, при напряжении сильнее; капли по стеклу, гром при ливне;
- **город**: шум, проезжающие машины со стереопроходом, редкий клаксон, сирена в кризисе;

## 8. Для слияния и дальнейшей работы

- Пробное слияние `git merge-file` от базы: с копией **redesign** без конфликтов. С копией **motion** конфликт один и ожидаемый: оба пакета дописали свой `<script>` перед `</body>`. Нужно оставить оба блока: `p21-sound` — последним, после скриптов моушна. `git merge-file --union` решает это автоматически.

- Блок `p21-sound` самодостаточен, CSS в нём свой (`.p21snd`, `#p21btn`, `#p21pop`).
- Чтобы озвучить новые анимации моушн-пакета, достаточно строки `window.SFX && SFX.play('имя')`.
- Для сюжета трёх сроков в пролог «4:09» и ночь «4:12» нужно поставить `SFX.scene('night')`, `SFX.play('clock.chime', {n: 4})`, `SFX.play('prologue.cut')` (титр «Восемнадцать лет назад»), а при наличии пакета ещё `SFX.playClip('prolog_409_a')`.
