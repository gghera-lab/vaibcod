# «Кабинет · три срока» — сценарий трейлера (75 с, 1920×1080, 30 к/с)

Тон: кино + сатира. Мрачное, медленное начало → сухой юмор и быстрая нарезка механик → нарастание тревоги → три срока → намёк на бункер → плашка.
Язык: русские титры, без диктора (голос Gemini можно добавить позже, если задать `GEMINI_API_KEY`). «Кошачья речь» — мяу-слоги из движка игры под репликами персонажей.
Музыка и звуки — из движка игры (генеративные темы `menu → oath → calm/vote → tense → crisis → termEnd`, эффекты `paper.stampBig`, `phone.ring`, `gavel`, `waxCrack`, `door.heavy` и т. д.).
Не раскрываем: финалы, развязки сроков; бункер и Полковник Тень — только мельком. Депутат и Министр не упоминаются. Сюжет «4:09 / ночь 4:12» не показываем (его ещё нет в игре).
