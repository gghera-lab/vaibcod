# Продукт

## Концепция

«Право на слух» — Telegram Mini App, где юридический текст воспринимается как хорошо поставленная аудиопрограмма и закрепляется активным вспоминанием. Название оставлено: игра слов («право на …» + «на слух») сразу объясняет формат.

**Позиционирование:** «Изучай право на слух. Не просто слушай — учись вспоминать».

**Бета:** озвучена только Конституция РФ — бесплатная демонстрация качества. Остальные документы — в каталоге с официальными ссылками и честным статусом «Озвучка в разработке»; голосование определяет очередь озвучки.

**Что не обещаем:** «100% запоминание», «весь закон за неделю», аудио несуществующих книг.

## Сегменты и УТП

| Сегмент | Задача | УТП | Первый сценарий |
|---|---|---|---|
| Студенты юрфаков (основной для MVP) | сдать конституционное право, не тонуть в тексте | «Конституция в наушниках по дороге + вопросы по каждой статье с цитатой» | глава 1 → тест главы → ежедневные повторения |
| Готовящиеся к экзаменам (гос. экзамен, магистратура, адвокатский) | системно повторить нормы | «Экзамен по главе, режим ошибок, честная статистика удержания» | экзамен по главе (Pro) |
| Практикующие юристы, юротделы | освежить нормы без чтения | «Актуальная редакция с датой сверки, слушать на скорости 1,5×» | сразу нужная статья из оглавления |
| Адвокаты и помощники | точность формулировок | «Текст первоисточника рядом с голосом, ссылка на pravo.gov.ru» | статья + проверка себя |
| Госслужащие | обязательный минимум знаний | «15 минут в день, прогресс по главам» | ежедневная цель |
| Изучающие право сами | понять основы | «Понятная структура: глава → статья → часть» | вступление → преамбула → глава 1 |

Основной сегмент MVP — студенты: высокая частота использования (сессии, семинары), доступность через студенческие Telegram-каналы, быстрая проверка спроса. Платёжеспособность ниже, поэтому Конституция бесплатна, а Pro — недорогой.

## Карта экранов

```
Онбординг (3 шага + согласие)
└─ Нижнее меню
   ├─ Главная: продолжить Конституцию · повторение на сегодня · статистика · последние документы · популярные кодексы · «Скоро в аудио» (голосование)
   ├─ Библиотека: поиск · категории · фильтры/сортировка · карточки документов
   │   ├─ Конституция РФ: редакция и сверка · продолжить · переход к статье № · главы → статьи (прослушано/сейчас/впереди)
   │   │   └─ Статья: текст с подсветкой · слушать/повторить · избранное · проверить, что запомнил · пред./след.
   │   └─ Документ: реквизиты · статус · источник · «Слушать» → «Озвучка скоро появится» · следить · голосовать · официальный текст
   ├─ Запоминание: повторение на сегодня · «Только ошибки» (Pro) · тесты по главам · сложные статьи · история
   │   ├─ Повторение: вопрос → ответ → разбор с цитатой → интервал
   │   └─ Тест: вопросы → результат → разбор ошибок
   ├─ Избранное: документы · статьи · закладки (слушать с места)
   └─ Профиль: подписка · статистика (14 дней, удержание — Pro) · настройки · уведомления · платежи · приватность · поддержка · документы · метрики (админ)
Плеер (полный экран): страница документа над тайм-баром · перемотка · ±15 с · скорость · таймер сна · закладка · главы · повторить · проверить себя · избранное · голос
Мини-плеер над нижним меню на всех экранах
Тарифы: бесплатно / Pro · месяц / Pro · год · тестовая оплата · восстановить доступ
```

## Дизайн-система

- **Цвета:** глубокий синий (`#13294b`–`#24508f`) — бренд и основные действия; графит/светлый нейтральный — фон и поверхности; один акцент — янтарный (`#f2b544`) для «сейчас звучит», выделения текста и Pro. Тёмная и светлая темы, по умолчанию — как в Telegram.
- **Типографика:** системный шрифт для интерфейса; PT Serif (OFL) для текста норм — «страница документа» как в режиме чтения справочных систем.
- **Компоненты:** карточки документов с «корешком», чипы категорий, списки, переключатели, нижние листы, тосты, кольца прогресса, плеер, состояния (загрузка, пусто, ошибка, офлайн).
- **Доступность:** зоны нажатия ≥44 px, подписи aria для иконок, фокус-рамки, уважение `prefers-reduced-motion`, безопасные зоны Telegram.
- **Без штампов:** нет молотков судьи и колонн — визуальный образ строится на звуке (эквалайзер) и тексте.

## Поведение кнопок (сводка)

| Элемент | Действие | Без подписки | Без данных/ошибка |
|---|---|---|---|
| «Слушать» у Конституции | старт/продолжение, открывается плеер | доступно | «Аудио временно недоступно», текст доступен |
| «Слушать» у других документов | лист «Озвучка скоро появится» | — | — |
| «Сообщить о выходе аудио» | заявка сохраняется на сервере, уведомление в боте при выпуске | доступно | тост с ошибкой |
| «Голосовать» | до 3 голосов на пользователя | доступно | понятная ошибка при лимите |
| Тест главы 3–9 | старт теста | экран «Доступно в Pro» | «Вопросы готовятся» |
| «Оплатить» | счёт Stars / тестовая оплата | — | «Оплата не подключена» при `disabled` |
| «Удалить аккаунт» | подтверждение словом УДАЛИТЬ + системный диалог | — | тост с ошибкой |
