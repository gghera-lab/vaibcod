# Аналитика

Собирается минимум: имя события и несколько параметров без содержания ответов и без персональных данных. Пользователь может отключить аналитику (Профиль → Приватность), при этом накопленные события удаляются.

## События (реализованы)

| Событие | Когда |
|---|---|
| `app_open` | запуск приложения |
| `onboarding_complete` | принятие условий в онбординге |
| `listen_start` / `listen_pause` / `listen_resume` | начало, пауза, продолжение прослушивания |
| `article_complete` | статья прослушана на ≥80% (фактическое время, без перемотки) |
| `article_replay` | «Повторить статью» |
| `quiz_start` / `quiz_finish` | тест по статье или главе (результат в %) |
| `review_answer` | ответ на карточку (тип, верно/неверно) |
| `favorite_add` / `favorite_remove` | избранное |
| `audio_notify_request` | «Сообщить о выходе аудио» |
| `vote_cast` | голос за озвучку |
| `document_open`, `document_listen_unavailable` | карточка документа; нажатие «Слушать» у неозвученного |
| `search` | поиск (только длина запроса) |
| `paywall_view`, `purchase_start`, `purchase_complete`, `purchase_cancel`, `purchase_failed` | воронка оплаты |
| `playback_error` | ошибка воспроизведения (код, офлайн) |
| `bookmark_add`, `sleep_timer_set`, `speed_change`, `voice_change` | функции плеера |

Длительность прослушивания и прогресс считаются не из аналитики, а из серверных таблиц `track_progress` и `daily_activity` (они нужны для работы продукта и статистики пользователя).

## Метрики и определения

| Метрика | Определение |
|---|---|
| Активация | доля пользователей, дослушавших хотя бы одну статью (≥80% трека) |
| Удержание D1 / D7 | доля пользователей, активных ровно на 1-й / 7-й день после регистрации; активность — ≥30 с прослушивания, ответ на карточку или вопрос теста |
| Возврат к обучению | доля пользователей с ответами в ≥2 разных дня |
| Изучено статей | среднее число дослушанных статей на пользователя |
| Конверсия в оплату | доля пользователей с оплаченным нетестовым платежом |
| Завершение тестов | завершённые / начатые тесты |
| Ошибки воспроизведения | `playback_error` / `listen_start` |
| Спрос на озвучку | голоса и заявки по документам |

Расчёт — `GET /api/admin/metrics` (экран «Метрики продукта» для администраторов, доступ по `ADMIN_TELEGRAM_IDS`). До запуска значения отражают только тестовые сессии и не являются показателями успеха.

Тестовые пользователи режима разработки исключаются из пользовательских метрик.
