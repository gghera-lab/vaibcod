## Что не проверено и требует внешней настройки

- **Прослушивание качества озвучки человеком** — в среде нет вывода звука; чек-лист в content/constitution/audio-qc-*.md.
- Запуск внутри настоящего Telegram (iOS/Android/Desktop): тема, BackButton, вибрация, `openInvoice`, фоновое воспроизведение при заблокированном экране — нужен бот и HTTPS-домен.
- Реальная оплата Stars и возвраты через Telegram — нужен бот (проверено на имитации обновлений Telegram в автотестах).
- Отправка сообщений ботом — нужен `BOT_TOKEN` (без него уведомления помечаются «пропущено»).
- Синтез через Yandex SpeechKit проверен вживую (2026-10-15): голос «Ермил», 163 трека, QC 0 ошибок, в плеере воспроизводится по умолчанию, подсветка текста синхронна. На слух человеком не проверен.
- PostgreSQL вне PGlite и Docker-образ — Docker в этой среде не установлен; миграции проверены на PGlite (тот же диалект PostgreSQL).

## Известные ограничения беты

- Бета-голоса Windows («Павел», «Ирина») скрыты из приложения (2026-10-15): в выборе голоса только SpeechKit — «Ермил» (готов) и «Алёна» («Озвучка этим голосом скоро появится»). Проверено в браузере и автотестом.
- В режиме по отдельным файлам (если файл книги не собран) автопереход в фоне может прерываться — поэтому по умолчанию используется файл книги.
- Сигнал между главами не звучит, когда приложение свёрнуто (чтобы не останавливать звук).
- Реферальная программа и сообщение о незавершённом уроке описаны в маркетинге, но не реализованы.
