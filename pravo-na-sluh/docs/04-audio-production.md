# Производство аудиокниги

## Конвейер

```
pravo.gov.ru (ИПС) ─┐
                    ├─ constitution:parse ─ constitution.json (структура, пометки отдельно)
kremlin.ru ─────────┘        │
                     constitution:verify ─ полнота + сверка с kremlin.ru → verification-report.md
                             │
  lexicon.json + overrides.json (ё, ударения, омографы, числа прописью)
                             │
                     constitution:script ─ speech/script.json (163 трека, 699 сегментов)
                             │   проверка: речь = текст нормы + только зарегистрированные замены; цифр не осталось
                     audio:synthesize ─ кеш сегментов (хэш содержимого) → обрезка тишины → паузы по сценарию
                             │          → нормализация (−19 dBFS речь, пик −1,5 dBFS, лимитер) → MP3 → manifest.json
                     audio:book ─ book.mp3 (склейка без перекодирования) + смещения треков
                             │
                     audio:qc ─ автоматические проверки + чек-лист ручного прослушивания
                             │
                     сервер (seed при старте) → плейлист → плеер
```

## Текст

- Источник: ИПС «Законодательство России», документ nd=102027595, получен 14.10.2026 (SHA-256 в verification-report.md). Редакция с изменениями от 04.10.2022 (ФКЗ № 5–8-ФКЗ).
- Редакционные пометки ИПС («В редакции…», «Дополнение частью…») хранятся отдельно и не озвучиваются.
- Отображаемый текст: типографская нормализация (кавычки «», тире, надстрочные индексы ¹), «ё» не добавляется.
- Полнота: 9 глав, 142 статьи (1–137 и 67¹, 75¹, 79¹, 92¹, 103¹), статья 127 — «исключена», 9 пунктов раздела второго, порядок частей и букв пунктов проверен автоматически.

## Сценарий произношения

- Все числа и надстрочные индексы текста (74 числовых токена) озвучены через 31 ручную замену с согласованием падежей: «из 450 депутатов» → «из четырёхсот пятидесяти депутатов», «в пункте „д¹“ статьи 83» → «в пункте „дэ точка один“ статьи восемьдесят три». Замена, которая перестала срабатывать (текст изменился), ломает сборку.
- Подписи структуры: «Статья шестьдесят семь точка один.», «Часть первая.», «Пункт „бэ“.», «Пункт первый.» (раздел второй).
- «ё»: 54 словоформы (её, лишён, отрешён, учёт, трёх, Вооружённые, признаёт, статьёй, судьёй…).
- Ударения: «о́рган/о́рганы» (без «организации»), «обеспе́чение», «уполномо́ченный», «догово́р», «пригово́р», «принуди́тельный», «распу́щена», «отреше́ние», «денонса́ция».
- Омографы по контексту: «права́ и свободы» / «международного пра́ва», «де́ла»/«дела́», «кра́я»/«края́», «о́круга»/«округа́», «ли́ца»/«лица́», «во́ды», «су́да», «счета́».
- Формат сценария нейтрален: ударение — знак U+0301, паузы — миллисекунды; адаптер Windows превращает это в SSML, адаптер SpeechKit — в «+» и `sil<[мс]>`.
- Файл для редактора: content/constitution/speech/speech-script.md.

### Как получить продакшн-голос (SpeechKit)

1. Yandex Cloud / AI Studio → сервисный аккаунт с ролью `ai.speechkit-tts.user` → API-ключ.
2. В `.env`: `YANDEX_API_KEY=...`.
3. Предварительная оценка стоимости: `npm run audio:synthesize -- --voice speechkit-ermil --dry-run`.
4. Синтез: `npm run audio:synthesize -- --voice speechkit-ermil` (кеш по фрагментам, повтор при 429/5xx). Оплата — за запрос до 250 символов, поэтому короткие фрагменты сегмента («Часть первая.» + текст) склеиваются в один запрос с паузой `sil<[мс]>`, длинные делятся по предложениям; звук запрашивается сырым PCM 22 050 Гц. Полная Конституция — 1003 запроса, около минуты при 4 параллельных запросах.
5. `npm run audio:qc` → прослушать выборку по чек-листу → исправить словарь → повторить (пересинтезируются только изменённые фрагменты).
6. В `content/voices.json` сделать голос `default: true`, перезапустить сервер.

`hidden: true` в `content/voices.json` убирает голос из приложения: при старте сервера его треки и профиль удаляются из БД, а пользователь, выбравший его раньше, слушает голос по умолчанию. Голос без готовой озвучки (сейчас «Алёна») виден в выборе с пометкой «Озвучка этим голосом скоро появится».

Перед публичным запуском проверить условия коммерческого использования синтезированной речи у выбранного провайдера и сохранить их в журнале прав (см. legal-questions.md).

## Звук

- Чистый голос без музыки. Опциональный короткий сигнал перед главой (Web Audio, отключается в настройках; в фоне не воспроизводится, чтобы не прерывать звук).
- Паузы: после «Статья N.» — 0,7 с; между частями — 0,65 с; между пунктами — 0,4 с; строки преамбулы — 0,25 с; конец статьи — 0,9 с; заставка главы — 1,4 с.
- Громкость: средняя громкость речи −19 dBFS, пик ≤ −1,5 dBFS, разброс между треками ≤ 0,6 дБ (факт по QC).
- Формат: SpeechKit — MP3 CBR 22,05 кГц моно 64 кбит/с, файл книги 66,1 МБ («Ермил»); бета-голоса — 16 кГц 48 кбит/с, 56,5 МБ («Павел»).

## Замена отдельной статьи

Исправили словарь или текст статьи → `npm run constitution:script` → `npm run audio:synthesize -- --voice <id> --tracks art-71` → `npm run audio:book` → `npm run audio:qc` → перезапуск сервера. Остальные файлы не меняются.

## Контроль качества

Автоматически (`audio:qc`, автотесты): все 163 трека на месте и соответствуют сценарию, MP3 без повреждённых кадров, длительность файла = манифест, темп 8–20 симв/с, пик ≤ −1 dBFS, громкость −24…−16 dBFS, таймкоды монотонны, смещения в книге возрастают. Результат: «Ермил» (SpeechKit) и оба бета-голоса — 0 ошибок, 0 предупреждений; средний темп «Ермила» 15,4 симв/с (у «Павла» 13,8) — если на слух быстро, задать `speed` в сценарии и пересинтезировать.

Вручную (обязательно, человеком): выборка из 10 случайных статей + 10 мест повышенного риска, чек-лист — в content/constitution/audio-qc-*.md. **Этот этап не выполнен**: в среде разработки нет возможности прослушивать звук.
