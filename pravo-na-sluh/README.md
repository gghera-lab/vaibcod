# «Право на слух» — Telegram Mini App

**Изучай право на слух. Не просто слушай — учись вспоминать.**

Бета-версия: полная аудиокнига **Конституции РФ** с текстом и подсветкой читаемого фрагмента, каталог законодательства (48 документов с проверенными реквизитами и ссылками на pravo.gov.ru; их озвучка в разработке), тренажёр запоминания (291 карточка, тесты по главам, интервальные повторения), подписка Pro через Telegram Stars.

## Что работает (проверено)

| Функция | Состояние |
|---|---|
| Текст Конституции | Загружен из ИПС «Законодательство России» (pravo.gov.ru) 14.10.2026, редакция с изменениями от 04.10.2022. Автосверка с kremlin.ru: 150/152 фрагмента дословно, 2 расхождения — пунктуация и служебная метка сайта |
| Аудиокнига | 163 трека (вступление, 10 заставок глав, преамбула, 142 статьи, 9 пунктов разд. II) голосом Yandex SpeechKit «Ермил» (2 ч 18 мин); плюс непрерывный файл книги для фонового прослушивания. Бета-голоса Windows скрыты из приложения (`hidden` в `content/voices.json`) |
| Плеер | Пауза/продолжение, ±15 с, перемотка, 0,75–2×, таймер сна (в т. ч. «до конца статьи»), закладки, главы, смена голоса с сохранением места, страница документа над тайм-баром с подсветкой и автопрокруткой, экран блокировки (Media Session), состояния загрузки/ошибки/офлайн |
| Каталог | Поиск по названию и номеру, 8 категорий, фильтры, сортировка, избранное, «Сообщить о выходе аудио», голосование (3 голоса на пользователя), честный экран «Озвучка скоро появится» |
| Запоминание | Вопросы 4 типов с цитатой из статьи для каждого ответа, тесты по статьям и главам, режим «Только ошибки», интервальные повторения (SM-2), сложные статьи, история |
| Профиль | Реальная статистика, серия дней, настройки, приватность (выгрузка и удаление данных, отказ от аналитики), поддержка, юридические документы |

## Быстрый старт (локально, без Telegram)

Нужен Node.js 20+.

```bash
npm install
```

```bash
cp .env.example .env
```

В `.env` для локальной разработки: `DEV_AUTH=true`, `PAYMENTS_MODE=sandbox` (PostgreSQL не нужен — используется встроенный PGlite в `./data`).

```bash
npm run dev
```

Откройте http://localhost:5173 — вход выполнится тестовым пользователем (жёлтая полоса «Режим разработки»).

Аудиофайлы в git не хранятся. На Windows бета-озвучку можно пересоздать командой `npm run audio:synthesize` (около 1–2 минут на голос), продакшн-озвучку — через SpeechKit (см. docs/04-audio-production.md).

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | API (8080) + Mini App (5173) |
| `npm test` | все автотесты |
| `npm run build` | сборка Mini App + проверка типов сервера |
| `npm start` | production-сервер (раздаёт и API, и собранный Mini App) |
| `npm run constitution:parse` / `:verify` | разбор официального текста и сверка с kremlin.ru |
| `npm run constitution:script` | сценарий произношения с проверкой соответствия тексту |
| `npm run constitution:cards` | сборка карточек с проверкой цитат |
| `npm run audio:synthesize -- --voice <id>` | синтез (кеш по фрагментам, пересинтез только изменённого) |
| `npm run audio:book` | пересборка непрерывного файла книги |
| `npm run audio:qc` | контроль качества аудио + план ручного прослушивания |
| `npm run audio:import -- --voice <id> --dir <папка>` | импорт записей диктора |
| `npm run catalog:build` | сборка каталога из результатов сверки с ИПС |
| `npm run finance:model` | финансовая модель (docs/finance-model.md) |
| `npm run bot:setup -w @pravo/server` | webhook, команды и кнопка меню бота |

## Что нужно от владельца для публичного запуска

1. Бот в @BotFather → `BOT_TOKEN`, `BOT_USERNAME`; Stars-платежи включены для бота.
2. Сервер в РФ с HTTPS-доменом (`PUBLIC_URL`), PostgreSQL (`DATABASE_URL`).
3. Продакшн-голос: синтезирован SpeechKit «Ермил» (163 ₽). Осталось прослушать по чек-листу `content/constitution/audio-qc-speechkit-ermil.md` и поправить ударения в словаре.
4. Юридическая проверка документов и вопросов из docs/legal/legal-questions.md; реквизиты оператора в документах.
5. Отключить `DEV_AUTH`, `PAYMENTS_MODE=stars`.
